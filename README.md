# Прогрес Електро

Приложение для сотрудников магазина «Прогрес Електро». В нём можно найти товар по названию, коду или штрихкоду, посмотреть цену и остатки по магазинам и оформить заказ в 1С.

Если пропадёт связь, можно искать товары в уже загруженном каталоге и собирать черновик заказа. Отправить его можно, когда связь восстановится.
