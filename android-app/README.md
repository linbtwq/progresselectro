# Прогрес Електро для Android

Android-проект Capacitor берёт интерфейс из корня репозитория. Каталог, сканер и черновик используют общий код сайта. APK содержит ресурсы приложения. После первого входа и загрузки каталога сохранённые данные доступны офлайн.

Для сборки на Windows нужны Node.js 22+, npm, JDK 21 и Android SDK Platform 36. Укажите `JAVA_HOME` и `ANDROID_HOME`, затем выполните из этой папки:

```powershell
npm ci
npm run apk
```

Тестовый APK находится в `android/app/build/outputs/apk/debug/app-debug.apk`. Обновления тестовых сборок на одном телефоне требуют той же подписи и подходящего номера версии.

При первом запуске войдите в Wi-Fi магазина и загрузите каталог. Для сканирования разрешите доступ к камере. HTTP разрешён для `192.168.1.23`; обмен с 1С требует сетевого маршрута до этого адреса. APK использует собственное локальное хранилище Android WebView. Каталог и черновики из браузера в него автоматически не переносятся.
