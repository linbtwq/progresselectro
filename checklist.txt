примеры на будущее (как расширять)

как использовать диалог подтверждения (showconfirmdialog)
функция возвращает promise (true/false). она уже стилизована и подключена.
пример: спросить подтверждение перед удалением товара.

async function askdelete(itemname) {
const ok = await showconfirmdialog({
title: 'удалить товар?',
message: вы уверены, что хотите удалить "${itemname}"?,
details: ['это действие нельзя отменить', 'товар исчезнет из списка'],
oktext: 'удалить',
canceltext: 'отмена',
danger: true // кнопка ok станет красной
});

if (ok) {
showtoast('товар удален');
// ... логика удаления
}
}

как использовать submitdocument для отправки на сервер
если нужно отправить данные (например, закрыть смену или отправить заказ), используется готовая функция submitdocument.
пример:

async function sendmyorder(orderdata) {
const btn = document.getelementbyid('sendorderbtn');

await submitdocument({
endpoint: 'orders', // путь на сервере 1с
payload: orderdata,
btn: btn,
successtext: 'заказ успешно отправлен!',
onsuccess: () => {
closetopmodal(); // закрываем модалку после успеха
}
});
}

текущее состояние и что делать дальше
api (бэкенд): сейчас в config.js стоит адрес от старого проекта (api.coffeemeters.pp.ua). когда будет готов сервер для прогреса — поменять url там.
сканер штрихкодов: работает из коробки. при сканировании отправляет код в searchgoodsbybarcode().
офлайн-режим: service worker кеширует страницу. если пропадет интернет, приложение откроется, но данные будут только те, что успели загрузиться в indexeddb.
очередь (queue.js): сейчас она пустая. когда появится логика отправки заказов или списаний, использовать функцию saveoffline(payload), если интернета нет. она сама отправит данные, когда сеть появится.
