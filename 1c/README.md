# Подбор и запись заказа покупателя

Сервис `progresselectrosite` принимает вход по ПИН и поиск номенклатуры. Для окна «Додати» добавь шаблон `/customer-order` и привяжи три метода.

| Шаблон | Метод | Обработчик |
| --- | --- | --- |
| /login | POST | POST_login |
| /login | OPTIONS | OPTIONS_login |
| /goods | GET | goodsget |
| /goods | OPTIONS | goodsoptions |
| /customer-order | GET | customerOrderGet |
| /customer-order | POST | customerOrderPost |
| /customer-order | OPTIONS | customerOrderOptions |

Вставь [Module.bsl](Module.bsl) в модуль сервиса. Существующие методы `/shipment` после обновления возвращают HTTP 410, чтобы старый сайт не создал расходную накладную.

Запись создаёт заказ с `КПК = Истина` в режиме записи без проведения.

Склад, организация и тип цен берутся из настроек пользователя. Получатель берётся из единственной действующей торговой точки. Если действующих точек несколько, задай код нужной в `КодОсновнойТочки` в модуле. Остаток подбирается для магазина и организации по товару без характеристики. В подбор попадают позиции с положительным остатком, однозначной ценой и основной единицей с коэффициентом 1.

На копии базы проверь открытие пустого подбора, поиск по названию и точному коду, сканирование, запись количества `1,25`. В 1С сверь номер, состав, торговую точку, магазин, организацию и установленный `КПК`. Заказ сверх остатка должен получить отказ. Повторная отправка может создать ещё один заказ. При записи заказа складской остаток должен сохраниться.

Скрипт проверки запускается в PowerShell 7 из корня проекта.

```powershell
./1c/Test-Service.ps1 -BaseUrl 'http://192.168.1.23/BasePE/hs/progresselectrosite'
```

Для подтверждённой копии базы добавь `-TestWrite` и введи `КОПИЯ` в запросе подтверждения. Если публикация требует Basic Auth, передай учётные данные через `-Credential (Get-Credential)`.
