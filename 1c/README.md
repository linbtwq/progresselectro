# Перенос HTTP-сервиса в новую базу

Модуль предназначен для конфигурации «Розничная и оптовая торговля», версия 4. У сервиса `progresselectrosite` в выгрузке нет шаблонов URL. Открой его в Конфигураторе и вставь содержимое `Module.bsl` в модуль сервиса.

Добавь шаблоны URL и методы в свойствах сервиса.

| Шаблон | Метод | Обработчик |
| --- | --- | --- |
| /login | POST | POST_login |
| /login | OPTIONS | OPTIONS_login |
| /goods | GET | goodsget |
| /goods | OPTIONS | goodsoptions |
| /shipment | GET | shipmentget |
| /shipment | POST | POST_Shipment |
| /shipment | OPTIONS | shipmentoptions |

## Настройки перед проверкой

- Укажи контрагента в общей торговой точке. Если в справочнике несколько действующих точек, заполни `КодОсновнойТочки` в функции `ОбщаяТорговаяТочка`. При одной действующей точке модуль выберет её автоматически.
- Для каждого пользователя настрой ПИН в поле `КодКарты`, привяжи сотрудника и заполни основные магазин и организацию. На всех пользователей действует одна общая точка. Сайт может по-прежнему передавать `point_id: "0"`.
- В документе `РасходнаяНакладная` добавь реквизит `ID_Запроса` типа «Строка», длина 64, переменная. Модуль проверяет наличие реквизита перед записью. Он нужен, чтобы при повторе запроса вернуть ту же накладную.
- Проверь настройки типа цен и основной валюты. Подбор отгрузки использует остаток организации и магазина по товарам без характеристики. Для проведения нужны однозначная цена и основная единица с коэффициентом 1. Количество поддерживает до трёх знаков после запятой, как в реквизите новой базы.

## Проверка на копии базы

1. Добавь маршруты, проверь модуль в Конфигураторе и опубликуй сервис копии базы. Базовый адрес для сайта имеет вид `http://<IP>/<публикация>/hs/progresselectrosite`.
2. Проверь вход двух пользователей и поиск по названию, части числового кода и известному штрихкоду.
3. Сверь остаток и цену одного товара с новой базой. Создай тестовую накладную с дробным количеством, например `1,25`, и проверь магазин, организацию, общую точку, получателя и списанное количество.
4. Отправь повтор с тем же `request_id` и тем же составом. Должен вернуться прежний номер. Повтор с изменённым составом должен получить ошибку. При попытке отправить больше остатка документ не должен появиться.

Сервис содержит маршруты текущего сайта. Старая очередь показаний `/meters` относится к кофейному приложению. Перед переключением адреса проверь, что у рабочих браузеров нет таких неотправленных записей.

## Проверка опубликованного сервиса

Для публикации `BasePE` базовый адрес имеет вид `http://192.168.1.23/BasePE/hs/progresselectrosite`. Запусти из корня проекта в PowerShell 7.

```powershell
$url = 'http://192.168.1.23/BasePE/hs/progresselectrosite'
$credential = Get-Credential -Message 'Учётная запись веб-публикации 1С'
./1c/Test-Service.ps1 -BaseUrl $url -Credential $credential
```

Скрипт попросит два ПИН-кода сайта и данные одного товара. Он проверит маршруты, вход, поиск и подбор отгрузки. Пароль публикации и ПИН-коды вводятся в отдельных запросах. Сверь напечатанные остаток и цену с 1С.

Для подтверждённой копии базы запусти тот же скрипт с параметром `-TestWrite`. После проверки цены и остатка введи `КОПИЯ`. Скрипт проведёт одну накладную на `1,25`, проверит повтор, изменение состава и превышение остатка. После этого сверь поля и движения накладной в 1С.

Если HTTP 401 появляется до входа по ПИН, сайт должен получить доступ к веб-публикации. Скрипт поддерживает её учётную запись через `-Credential`. Для браузерного доступа пароль публикации следует хранить на стороне сервера, если используется прокси.
